# Multi-Agent-Research-System

Using multi-agent to search about topic scape data then consturct a report  

## create new enviroment
```bash
conda create -n mutli-agent

conda activate mutli-agent
```
 
## install requirements 
```bash
pip install requiremts 
```

## How to use

change the prompt to what you want to get a report about 
then  
```bash
python main.py
```
